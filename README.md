# Bittu AI

Bittu AI is a native Android AI assistant app with a ChatGPT-style dark interface.

## Features

- Chat-style task input
- AI coding assistance
- Code output in the app
- Dark theme
- Voice input planned
- Research, documents, agents and automation planned

## Build APK with GitHub Actions

1. Open the **Actions** tab in this repository.
2. Run the **Build Bittu AI APK** workflow.
3. Download the APK from the workflow artifacts.
